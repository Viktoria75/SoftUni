# Soft Uni Project

## Project Overview

SoftUniProject is a Windows Forms application developed as a final project for the SoftUni C# Programming Course (2021). This project serves as a comprehensive employee and company management system. It allows users to register, log in securely, and manage their profiles along with company details. The application uses a MySQL database with Entity Framework Core for data persistence and follows a modular, layered architecture. Key features include user authentication, registration, a personalized main menu, and robust data access through DAO (Data Access Object) patterns. The project demonstrates best practices in C# development, including dependency injection, secure password handling, and session management.
